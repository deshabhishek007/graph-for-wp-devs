# Third-party notices and provenance

## WordPress

Graph packs are generated from official WordPress release archives downloaded from `https://wordpress.org/`. WordPress is distributed under GPL-2.0-or-later. Each pack manifest records the exact release, archive URL and SHA-256, checksum API, number of verified files, and source licence. The repository does not commit the downloaded WordPress source.

Official licence statement: https://wordpress.org/about/license/

## Graphify

Graphs and reports are generated with the `graphify` CLI from the `graphifyy` Python package. Graphify is distributed under Apache-2.0. Each manifest records the exact Graphify version and build mode. Graphify itself is not vendored into this repository; its project-scoped integration files are generated by its installer.

Official project: https://github.com/Graphify-Labs/graphify

Generated WordPress pack data is distributed under GPL-2.0-or-later to preserve WordPress provenance. Repository-authored scripts, schemas, integrations, and documentation are distributed under Apache-2.0 unless a file says otherwise.
